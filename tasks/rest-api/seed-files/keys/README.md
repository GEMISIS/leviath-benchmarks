# JWT Signing Keys

These RS256 key pairs are used for JWT token signing.

- `private.pem` - Private key for signing tokens
- `public.pem` - Public key for verifying tokens

**IMPORTANT**: These are test keys only. Never use in production.

Key details:
- Algorithm: RS256 (RSA with SHA-256)
- Key size: 2048 bits
- Format: PEM
